# Dati del progetto

Il sistema utilizza i file CSV `2020.csv` ... `2025.csv` (44 colonne omogenee). In particolare `ingestion.py` richiede `2025.csv`, mentre `batch_job.py` legge tutti i file `*.csv` presenti in questa cartella. I dati originali non sono distribuiti nel repository pubblico: per avviare il progetto occorre collocarli qui, rispettando licenze e condizioni di utilizzo.

Le immagini decorative `sfondo.jpeg`, `ao.jpeg`, `rg.jpeg`, `wim.jpeg`, `uo.jpeg` sono facoltative e non sono incluse nel repository pubblico in assenza di informazioni sui diritti di distribuzione.
